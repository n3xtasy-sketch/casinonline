# PROJECT.md — CasinOnline.ro

## Project name

CasinOnline.ro

## Project type

Premium Romanian casino affiliate discovery platform.

This is not intended to look or behave like a traditional affiliate blog.

The product should feel closer to a modern casino discovery app, combining:

* casino comparison
* game discovery
* bonus discovery
* provider exploration
* payment information
* expert reviews
* guides
* filters
* search
* favorites
* comparison tools

The platform should look modern, fast, premium and trustworthy.

---

# Main objective

Build one of the strongest Romanian casino affiliate platforms from both:

* SEO
* UX
* technical performance
* conversion
* content depth
* internal linking
* user retention

The platform should be able to scale from tens of pages to thousands of pages without needing to be rebuilt.

# URL philosophy

URLs should be:

* descriptive
* short
* stable
* predictable

Avoid unnecessary date folders.

Avoid query parameters for indexable content when a stable URL is appropriate.

Avoid changing URLs once pages are established.

---

# Content quality

Each indexable page should have a clear purpose.

Do not create programmatic pages solely because data exists.

A page should provide meaningful unique value.

Avoid creating thousands of thin pages.

---

# AI and search visibility

Content should be easy for search engines and AI systems to understand.

Prefer:

* clear definitions
* direct answers
* structured tables
* factual data
* expert commentary
* clear entity relationships
* concise summaries

Avoid writing specifically for bots.

Write primarily for the user.
